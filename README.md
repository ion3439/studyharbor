# 学藏 StudyHarbor

**少一点来回找，多一点学进去。**

学藏是一个本地优先的学习资料收藏工具。把散落在浏览器里的课程、文章、视频和下载页面放进一个资料库，按主题查找，记住上次学到哪里。

这个项目从一个真实需求出发：学习运筹学时，搜到了很多课程、教学文章和讲义下载页面，却总在多个地方来回找。第一版专注于把入口和学习进度整理清楚。

## 第一版能做什么

- **集中收藏**：保存课程、文章、视频、下载资料、练习 / 代码的链接。
- **按主题整理**：自由填写主题和标签，例如“线性规划”“整数规划”“图论与网络优化”。
- **全文检索已填写信息**：搜索标题、链接、主题、标签、笔记、学习位置和本地文件位置。
- **记录学习进度**：待学习、学习中、已完成，并可填写课时、页码、视频时间点。
- **重点收藏**：给常回看的资料加星。
- **查找下载文件**：记录下载网页和本地文件位置；复制位置后到文件管理器打开。
- **数据可带走**：JSON 导入 / 导出，Markdown 阅读清单导出。导入合并，不覆盖已有同链接记录。
- **运筹学示例库**：内置 6 个来自 MIT OpenCourseWare 与 Google OR-Tools 官方网站的入口；示例笔记和进度均为演示，支持一键移除。
- **适配窄屏**：电脑、平板和手机浏览器均有对应布局。

应用不需要账号、API Key、付费服务或第三方依赖。

## 第一次使用

### Windows

1. 安装 [Node.js](https://nodejs.org/) 20 或更新版本。
2. 下载并解压项目源码。
3. 双击项目里的 **`启动学藏.cmd`**，保持启动窗口打开。
4. 在浏览器访问 **http://127.0.0.1:4173**。
5. 点击“收藏资料”，粘贴一个链接，填写标题并保存。

### macOS / Linux 或终端启动

在项目目录中运行：

```sh
node scripts/serve.mjs
```

然后访问 http://127.0.0.1:4173。按 `Ctrl+C` 停止服务。

这个项目无需安装依赖。也可以使用已安装的 npm 执行 `npm start`。

> 请保持网站地址和端口一致。`localhost` 与 `127.0.0.1` 在浏览器里是不同的数据空间。不要依赖直接双击 HTML 文件时的存储行为，推荐按上述方法启动。

## 一次典型的整理

假设找到一篇单纯形法教程：

1. 在“收藏资料”中粘贴网址，标题写“单纯形法：从例题理解迭代过程”。
2. 主题填“线性规划”，类型选“文章”，标签填“入门, 单纯形法”。
3. 开始学时，把状态改为“学习中”。
4. 离开前编辑资料，在“学到哪里了”写“例题 2，第 3 次迭代”。
5. 如果下载了 PDF，把文件位置记在“本地文件位置”里。
6. 下次打开“学习中”或搜索“单纯形法”，就能找到入口和学习位置。

搜索框支持多个关键词；快捷键 `/` 可聚焦搜索框。点击卡片中的主题或标签也可筛选。

## 数据、备份与边界

- 资料保存在**当前浏览器、当前设备、当前网站地址**的 `localStorage` 中，不自动同步到其他设备。
- 清除站点数据、更换浏览器、无痕会话结束等操作可能让资料不可用。请定期点击“导入 / 导出 → 导出全部资料 · JSON”。
- **JSON 是恢复备份**。Markdown 适合阅读和分享，不能代替 JSON 恢复。
- 备份包含你填写的所有信息，包括笔记和本地位置。分享前检查其中是否有私人内容。
- 导入会先验证全部记录；相同规范化链接保留当前资料，跳过导入记录。链接中的片段 `#...` 不参与去重，查询参数仍保留。
- 单次导入最多 20 MB、5000 条，实际可保存数量也受浏览器存储空间影响。
- 不上传收藏内容，不自动抓取网页，不保存账号密码。打开外链后会访问原网站。
- 本地文件位置只是检索提示，不上传、搬动或删除本地文件。实际下载文件也不包含在备份中。
- 示例内容只保存入口，不复制或再分发课程正文和教学文件；相关内容权利归原作者或网站所有。

## 项目结构

```text
dist/
  index.html      页面和表单
  styles.css      界面与响应式布局
  app.js          收藏、浏览器存储和交互
  core.js         数据验证、搜索、去重、备份合并
  icon.svg        原创图标
scripts/
  serve.mjs       仅监听本机的静态服务
tests/
  core.test.mjs   核心数据行为检查
docs/
  FIRST_PROJECT.md  新手使用与维护路线
  PUBLISH_GITHUB.md GitHub 发布步骤
  VERIFICATION.md   当前版本验证记录
```

## 开发与验证

使用 Node.js 20 或更新版本，无需安装依赖：

```sh
node --check dist/app.js
node --check dist/core.js
node --test tests/core.test.mjs
```

有 npm 时也可以运行 `npm run check`。GitHub Actions 配置会对代码语法与核心行为进行检查。

如要部署静态网站，将 `dist/` 中的文件作为站点根目录即可。也可以将整个仓库发布到 GitHub Pages：选择包含源码的分支与 `/ (root)`，根目录的 `index.html` 会自动打开 `dist/` 中的应用。仓库自带 `.nojekyll`，无需额外构建。

部署后的网站与本地网站是独立存储空间，切换前请导出、导入 JSON。

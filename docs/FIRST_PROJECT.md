# 你的第一个项目：先用起来，再逐步维护

## 现在已经准备好的内容

代码、界面、数据备份、核心检查、说明文档和 GitHub 问题模板。

## 你第一次试用时做什么

1. 添加 3 份你真正想学的运筹学资料。
2. 为它们设置自己能理解的主题。
3. 学完一小节，写下停下的位置。
4. 关掉页面，再打开，检查资料是否还在。
5. 导出一次 JSON，保存在自己记得的位置。
6. 把最不顺手的一步记录下来，作为下一次改进任务。

页面里的运筹学资料和进度是示例。编辑后保存的示例会成为你自己的记录，不再被“移除示例”删除。

## 你作为维护者可以做什么

维护者不仅写代码，也决定哪些问题值得解决，检查改动是否可靠，回应使用反馈并更新说明。

可以先从这些小事开始：

- 根据自己的使用体验修正一个不清楚的提示。
- 记录一个可复现的问题。
- 邀请愿意试用的人反馈，并如实记录。
- 完成一个具体改进后更新版本说明。

维护记录应真实反映发生过的工作；不要补造用户、使用量或贡献历史。

## 关于开源支持计划

做出并发布项目，不代表自动符合任何资助或赠送计划的条件。是否申请，应根据申请时的官方规则和已经形成的真实维护经历判断。

此项目本身应先给你带来实际价值。
